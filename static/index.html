Sẵn sàng cho buổi luyện tập

  1. Tạo API key trong Google AI Studio ↗ và kiểm tra project chưa bật billing.
  2. Sao chép .env.example thành .env. Điền GEMINI_API_KEY và đổi GEMINI_FREE_TIER_CONFIRMED=true khi đã kiểm tra.
  3. Khởi động lại server. Không gửi API key trong cuộc trò chuyện hoặc commit lên GitHub.
Ngân sách được tính thế nào?

Mỗi chat bắt đầu với 2.000 token. Chỉ trừ tin nhắn mới và output, gồm thinking của model. Không trừ lại lịch sử hoặc system prompt. Hết token sẽ dừng sinh, có thể giữa câu/code.

Khi bấm Dừng hoặc mất kết nối mà chưa có usage cuối, phần output đã giữ chỗ được tính hết để tránh hoàn nhầm token. Bộ đếm khi chưa có API chỉ là ước lượng.

Web không xác minh được billing từ API key. Free Tier hết quota thì dừng; không có cơ chế chuyển dịch vụ trả phí.
